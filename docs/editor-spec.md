# 编辑器交互规范

## 1. 整体布局

```
┌──────────────────────────────────────────────────────────────┐
│ 顶栏：品牌 / 配置档名 / 保存状态 / 撤销重做 / 模式 / 试演 / 导出 │
├──────────┬────────────────────────────────┬──────────────────┤
│ 配置档库  │ 预览舞台（真实引擎）             │ 属性检查器        │
│ 搜索/新建 │ 分辨率/缩放/低动效/高对比/慢放     │ 属性|音频|JSON|校验│
│ 卡片列表  │ 从头/当前幕/停止 + 审计浮层       │ 全局 + 七幕       │
├──────────┴────────────────────────────────┴──────────────────┤
│ 时间轴：七幕泳道 + 弹窗序列点 + BGM 波形 + 从选中幕试演          │
└──────────────────────────────────────────────────────────────┘
```

- 三个分隔条可拖拽；比例保存在 `settings.json`（`layout`）。
- 窗口几何、比例、预览环境、上次配置档与编辑上下文在正常退出时保存。
- 编辑器 UI 复用演出侧设计令牌；危险操作只允许使用警示红。

## 2. 双模式

- **向导模式**：五步（模板 → 写信 → 弹窗 → 蛋糕 → 完成）。首次启动且没有配置档时自动打开。
- **专家模式**：三栏 + 时间轴全功能。
- 顶栏「专家/向导」按钮随时切换；选择持久化。向导编辑的就是同一个 profile，不会产生第二份数据。

## 3. 配置档库（E-02 / E-03 / E-08）

- 卡片：缩略图、显示名、寿星、主题徽标、修改时间。
- 搜索：按显示名/寿星过滤。
- 新建：模板（毛玻璃庆典/卡通立体）→ 自动落到 `profiles/<id>/`。
- 右键：打开、复制、导出 `.bbp`、快照历史、在资源管理器显示、移入回收站。
- 删除：移入 `%APPDATA%/BirthdayStudio/trash/`，保留 30 天，可恢复。
- 导入 `.bbp`：解压到新 id，保留 assets；导出 `.bbp` 不包含 journal/snapshots。

## 4. 自动保存（E-04 / E-05）

三层防线：

1. **800ms 防抖**：任何编辑 → dirty → 800ms 无输入 → 写盘。
2. **原子写**：`profile.json.tmp` → flush → fsync → `os.replace`；断电不会产生半截 JSON。
3. **journal**：`journal.jsonl` 记录 `open/save/snapshot/close`；启动时最后事件不是 `close` 判定为崩溃。

- 顶栏常驻状态：`● 已自动保存 HH:MM` / `○ 保存中…` / `⚠ 保存失败：…`；失败必须显式告警。
- **滚动快照**：距上一快照 ≥5 分钟且有改动 → 全量快照；滚动保留 10 份。
- **无效字段也保存**：草稿可以暂时不满足 schema（黄框 + 回退预览），避免丢失输入；导出仍被错误阻挡。
- 撤销/重做：会话内 100 步；连续拖动同一字段在 800ms 内合并为一步。

## 5. 崩溃恢复（E-06）

```
启动
 ├─ 扫描 journal
 │   ├─ 全部 close → 正常恢复上次配置档（E-07）
 │   └─ 发现未关闭 → 弹出恢复对话框
 │        ├─ 恢复并继续（默认：最后一次自动保存）
 │        ├─ 从所选快照恢复（覆盖当前 profile）
 │        └─ 放弃未保存更改（有快照则回到最新快照）
 └─ 恢复后打开配置档，并还原幕/选中项/播放头/滚动位置
```

## 6. 重启自动加载（E-07）

`settings.json` 记录：

- `last_profile_id`、`startup_restore`；
- `editor_mode`（wizard/expert）；
- 窗口几何、三栏比例、时间轴高度；
- `preview`：分辨率、缩放、静音、慢放、审计浮层、低动效；
- `contexts.<profile-id>`：当前幕、选中元素、播放头、滚动偏移；
- `plugins.enabled`。

所有自动行为可在设置中关闭。

## 7. 预览舞台（E-10）

- 预览内嵌的是 **同一个 ShowStage**；配置热更新通过 `session.preview` 传递（无效字段回退到上一次有效值）。
- 播放控制：从头、从当前幕、停止；空格/回车在演出内推进，F5/F6 快捷键。
- 环境模拟：1080p/1440p/4K、50–200% 缩放、低动效、高对比、0.5× 慢放、静音、审计浮层。
- 审计浮层：显示错误/警告计数与前 3 条；完整列表在「校验」页。
- 预览右上角常驻音频条，右下角常驻跳过键（可跳过幕时）。
- 停止时显示封面海报：配置档名、寿星、七幕点位、试演按钮。

## 8. 属性检查器与校验中心（E-09 / E-14）

- 左侧标签：全局 + 七幕 + 启用状态；未启用的幕变暗。
- 表单按类型自动选择控件：文本、长文本、数字、滑块、开关、颜色、下拉、字体、资源路径（带浏览/导入）。
- 每个字段右侧有「恢复默认」；每幕有「恢复本幕默认」。
- 字段级校验：错误红、警告黄；下方显示消息。
- **音频页**：统一上传/试听 BGM 与祝福语音；语音在火漆碎裂时播放一次，播放期间自动压低 BGM，播完恢复。
- **JSON 页**：完整 `profile.json` 源码，可编辑 → 「应用 JSON」→ 解析/校验/热更新；解析错误就地提示。
- **校验页**：错误/警告列表，点击条目跳到对应幕；导出闸门说明；三条健康红线摘要。

内置 lint 规则（导出时错误必须清零）：

| 规则 | 级别 | 说明 |
|---|---|---|
| schema / 类型 / 范围 | error | Pydantic 校验 |
| 信纸墨色与纸张对比 <4.5:1 | error | WCAG AA |
| 主题角色对对比 <4.5:1 | error | WCAG AA |
| 弹窗强调色导致正文对比不足 | warning | 估算 |
| BGM/图片/字体资源缺失 | error | 导出会失败 |
| 主音量/BGM >50% | warning | 安全聆听 |
| 弹窗同屏 >7 | warning | 认知负荷 |
| 弹窗总入场 >10s | warning | 注意力窗口 |
| 弹窗正文可能溢出 | warning | 尺寸估算 |
| 彩带爆发 >3 | error | 光敏红线 |
| 确认卡 <44px | error | 目标尺寸 |

## 9. 时间轴（E-11）

- 七幕泳道：启用圆点、幕名、估算时长、按总时长比例绘制条形；点击选中，双击从该幕试演。
- 弹出卡片序列：在「祝福」泳道下方按 startDelay + stagger 显示圆点。
- BGM 波形：视觉概览（非真实 FFT）。
- 播放头：预览运行时定位到当前幕起点。
- 拖拽分隔条调整时间轴高度；单幕时长在属性面板中编辑。

## 10. 轨迹绘制器（E-12）

- 属性 → 祝福 → 轨迹 → 「手动绘制轨迹…」。
- 在网格画布上按住鼠标拖动；采样点归一化为 0..1 保存为 `custom_points`，`preset` 自动切到 `custom`。
- 轨迹按卡片数量重采样，换分辨率不跑偏。
- 预设轨迹（爱心/圆弧/环形/波浪/螺旋/对角线）仍可在下拉框选择。

## 11. 资源管理器（E-13）

- 属性 → 全局 → 资源库：列出 assets 的文件名/类型/许可证；可打开文件、导入新素材。
- 导入按 sha256 内容去重；同名不同内容不会覆盖。
- 版权字段随资源记录，导出向导会提示确认。
- BGM/弹窗配图等路径字段的「浏览」按钮同样走导入流程。

## 12. 快捷键

| 快捷键 | 动作 |
|---|---|
| `Ctrl+S` | 立即保存（强制 flush） |
| `F5` | 从头试演 |
| `F6` | 从当前幕试演 |
| `Ctrl+E` | 打开导出（无错误时） |
| `Esc` | 停止预览 / 关闭对话框 |
| 演出内 `Space` / `Enter` | 推进当前幕 |
| 演出内 `Esc` | 播放器退出 |

## 13. 数据目录

```
%APPDATA%/BirthdayStudio/
  settings.json
  profiles/<id>/...
  trash/
  plugins/
  logs/app.log
  cache/plaque_*.png
```
